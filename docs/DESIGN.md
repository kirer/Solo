# 界面设计（锁定稿）

> 这份文件是**决策**，不是建议。改它要先说明为什么原决策错了。
> 依据：`design-taste-frontend` skill 的 app-screens 章节 + 摇出的 `Framed sheet` 方向（seed 3117）。
> 检验方式：`node ~/.pi/agent/skills/design-taste-frontend/scripts/inspect.mjs <url> --app`，**必须 0 FAIL**。

## 0. 为什么是这个方向（第三版：对齐 DSH）

> 版本史：v1「深色仪表盘」→ v2「取景框 + 白纸（暖石色 + IBM Plex）」→ **v3 = 现在这一版**。
> 每一版都留下前一版为什么不够，因为下一轮改的人一定会想「要不加点颜色」。

v2 的实测是 0 FAIL，但老大看完的结论是「很垃圾，去学 ds-bot」。原因不在纪律，在**骨架**：

- v2 是「一张纸上漂着一块纸」，v3 是**两栏到底**（侧栏 280 + 主列），logo 长在侧栏头顶。
  这是任何桌面聊天应用的第一性结构，也是 v2 缺的那一层。
- v2 用 webfont（IBM Plex）给一个中文界面定型，结果一眼就能看出「这是个网页」；
  DSH 用**系统 UI 字体栈**，在 macOS 上就是原生。这一条换掉之后，观感差一个量级。
- v2 的正文字号在 10–16px 之间挤了六档，层级靠加粗和颜色硬撑；v3 只有 **14/24 + 13/20** 两条主线。

所以 v3 的全部数值来自 DSH 源码（`/tmp/dsh`，规格摘要在提交信息里），不是目测。
**规则还在，只是骨架换了。**

## 1. 外壳：两栏到底

```
┌──────────┬──────────────────────────────────────────┐
│ ☾ Solo    │ 知言  负责人  待命        ⟨团队⟩⟨设置⟩⟨详情⟩│ 56px，下边 0.5px
├──────────┼──────────────────────────────────────────┤
│ 工作区   │                                          │
│ ○ 知言   │        知言  负责人  20:08               │
│   待命   │        Solo 项目已立并开工…              │
│ ○ 全員   │        ✓ 知言 已完成，用时 90 秒 ›       │
│ …        │                     老大 21:14  ○        │
│          │                     ┌──────────────┐     │
│          │                     │ 一句话：…    │     │
│          │  ┌──────────────────────────────────────┐│
│          │  │ ＋  发消息…                        ↑ ││ 52px 圆角 28
└──────────┴──┴──────────────────────────────────────┴┘
```

- **侧栏 280px，整列到底，右侧 0.5px `--line`。** 没有横贯的顶栏，logo 在侧栏自己的头上
  （DSH 的 `SidebarRoot` 结构）。手机折叠成单区域（§1.3）。
- **主列**：标题行 56px（下边 0.5px）→ 消息流 → 输入区。标题是 15/20/500，不是 22/600 的大标题
  —— 大标题会把眼睛从消息上拽走。
- **消息列宽 `min(100% - 32px, clamp(680px, 64%, 920px))`，居中。** 这一条决定「工整」：
  宽窗口不让一行拉成 130 字，窄窗口不挤成五六个字。输入卡跟着它走（列宽 + 32）。
- **不用色彩分层。** 层次只靠 `--frame`（侧栏）↔ `--ground`（主区）↔ `--field`（输入卡/气泡）三档灰。
- **0.5px，不是 1px。** 侧栏右边、标题行下边、输入卡描边全是发丝线；输入卡的描边画在
  `box-shadow: 0 0 0 0.5px` 里，不占布局。

### 1.0 侧栏可收起

logo 行右侧一个 28px 按钮，点一下整列收到 **56px 的图标条**（DSH 的 rail），再点展开。
状态存 `localStorage["ai-company.side"]`，刷新后保持。

- **收起只由一个属性驱动**：`.frame[data-side="rail"]` 换掉 `--sidebar`，其余规则全部从它派生。
  JS 不碰任何尺寸 —— 尺寸写在 CSS 里，只有一个家。
- 收起后每行是 **36×36 的方块**，只剩头像；名字、预览、时间收起来，未读退化成右上角一个 7px 点
  （数字放不下，但「有东西」这件事不能丢）。
- **名字挪进 `title` 属性**：收起后看不见名字，悬停能读到「知言 · 你在吗」，读屏也读得到。
- 宽度是 `transition: grid-template-columns 300ms cubic-bezier(.4,0,.2,1)`，`prefers-reduced-motion`
  时关掉 —— 它是整列在滑，不是内容被挤变形。
- **手机上不提供**：手机侧栏本来就是整屏的一个区域，没有「收」这回事。

### 1.1 侧栏：**一列平铺，两行**

**没有分组。** 老大原话：「左侧栏太乱，不要分组，直接平铺。」所以侧栏就是一列，群、项目、私聊
按最后活跃时间倒序。每行两行文字：

- 第一行：名字（14/20，500）+ 状态（11px `--ink-3`，只在私聊行）+ 右侧相对时间（10px `--mono`）。
- 第二行：最后一句（12/18 `--ink-3`，单行省略）。

状态只有四种：`在想` / `在做` / `待命` / `睡了`，只有「在做」用 `--live`。

**不显示**：职位、项目名、成员数、分组标题。私聊点开之后，这个人的状态改到标题行里显示。

两行是必须的：只剩名字和时间时，一眼扫过去全是同一批名字，分不清哪个频道真的动了。

### 1.2 右侧栏：**第三列**

详情、文件都住在右边这一列（`.frame` 的第三列），宽度 `--rightbar` 从 **0 过渡到 360**。
它不是浮层：**展开时中列真的变窄**（820px），因为盖住的浮层在写长消息时是灾难。

- **两帧打开**：先 `hidden=false`，下一帧才把 `data-right` 改成 `open` —— 同一帧改两样，
  浏览器会直接跳到终态，动画不存在。
- **列 300ms、内容 240ms 带 60ms 延迟**，同一条 `cubic-bezier(0.4, 0, 0.2, 1)`：
  先让列让开、字后进来，否则内容会在半宽里被挤着重排一遍。
- **收起等滑完再 `hidden`**：直接隐藏等于把动画剪掉，右边会「啪」地弹一下。
- **两个 tab（详情 / 文件）**，下划线从中间 `scaleX(0→1)` 长出来 —— 换页时眼睛跟着那条线走。
- 换频道时列**不收起**，内容原地淡出淡入（它现在属于布局，收起来会让中列宽度跳一下）。
- 手机上退回整屏浮层（`position: fixed; inset: 0`），列宽不参与。

「文件」页是工作区的只读视图：绝对路径校验在工作区里，前端不做 `..` 判断；
二进制只报大小，文本文件用等宽字体显示原文（`**` 不渲染成粗体 —— 老板要看 agent 到底写了什么）。
每行落下的动画错峰 `14ms`，一眼看得出「这是刚加载的」。

### 1.3 需要老大的消息 = 「找你」

后端把「这条要不要老大看」判好了（`needsYou`，判据是核心的 `needsOwner()` 或显式 `@老大`）。
界面做三件事：

1. **就地标记**：左侧 2px `--accent` 竖线 + 12px `需要你`（`--accent`，无底色，不是药丸）。
2. **标题行计数**：`GET /api/attention` 的 `unread`。0 件时整块隐藏（显示一个灰色的 0 是噪音）。
3. **跨频道定位**：点开浮层，按时间倒序列出所有频道里等老大的消息，点一行切频道 + 滚到该 seq + 高亮。

**这是本产品回答「消息太多、我找不到该看哪条」的唯一机制，不许省。**

### 1.4 手机（≤640px）

侧栏与主列**叠在同一格**，靠 `body[data-pane]` 决定谁可见：列表铺满 → 点一个频道推进会话 →
返回回列表原位置。标题行 48px（返回 + 标题 + 三个图标），标题必须留（不留就是一片空白）。

## 2. Token（全部锁定，不许新增颜色）

取自 DSH 的 `--dsw-alias-*` 语义层，值是对应 `--dsw-static-*` 的字面量。

```css
:root {
  /* 面：侧栏比主区低一档，输入卡/气泡再高一档 */
  --frame: rgb(249 250 251);   /* 侧栏 */
  --ground: rgb(255 255 255);  /* 主区 */
  --field: rgb(255 255 255);   /* 输入卡 */
  --raised: rgb(245 246 247);
  --hover: rgb(38 49 72 / 0.06);
  --active: rgb(38 49 72 / 0.1);
  /* 线：只有三档，主流是 0.5px */
  --line: rgb(0 0 0 / 0.1);
  --rule: rgb(0 0 0 / 0.04);
  --control: rgb(0 0 0 / 0.16);
  /* 墨：primary / secondary / tertiary */
  --ink: rgb(15 17 21);
  --ink-2: rgb(97 102 107);
  --ink-3: rgb(129 133 140);
  /* 强调：deepseek-500（浅）/ deepseek-400（深）。界面里所有的「蓝」都是它 */
  --accent: rgb(65 118 230);
  --accent-wash: rgb(237 243 254);  /* 老大自己说的话 */
  --live: rgb(65 118 230);
  --warn: rgb(245 158 11);
  --danger: rgb(236 19 19);
  /* 圆角 6 档 + 满圆，混用会显廉价 */
  --r-xs: 4px; --r-control: 8px; --r-row: 12px;
  --r-sheet: 16px; --r-xl: 20px; --r-panel: 28px; --r-pill: 999px;
  --sidebar: 260px;
  --pad: 16px;
}
```

**规则：**

1. **颜色只上数据，不上 chrome。** 强调色只出现在：2px「需要你」竖线、`--live` 小点、
   焦点环、发送键、链接、以及老大自己说的话的底色。没有彩色按钮、没有彩色胶囊、没有彩色图标底。
2. **一个强调色。** 不许再引入第二个蓝色或任何绿色（v2 的深松绿已废）。
3. **用户气泡 = `--accent-wash`**（浅 `rgb(237 243 254)`，深 `rgb(68 68 70)`）。
4. **状态色只用于真出问题**（失败、超时）。零和正常一律 `--ink-3`。
5. **不许渐变、不许发光、不许玻璃。** 阴影只允许两处：输入卡（`0 0 0 0.5px` 描边 + 3% 扩散光）、
   浮层菜单。
6. **0.5px 是默认线宽**，1px 只在真正需要强调的边框上。

### 2.5 深色主题

同一批 token 名，`[data-theme="dark"]` 里换值，五个样式表一个字节都不改。
三档：`system` / `light` / `dark`，存 `localStorage["ai-company.theme"]`，落成 `<html data-theme>`；
`<head>` 里那段同步内联脚本先落色（否则刷新时闪一下白）。

| token | 深色 | 说明 |
|---|---|---|
| `--frame` | `rgb(27 27 28)` | 侧栏。**比主区略亮** |
| `--ground` | `rgb(21 21 23)` | 主区/页面底，最深 |
| `--field` | `rgb(44 44 46)` | 输入卡、老大气泡 |
| `--raised` | `rgb(44 44 46)` | 代码块、tip |
| `--line` | `rgb(255 255 255 / 12%)` | 发丝线 |
| `--ink` | `rgb(249 250 251)` | 14.9:1 |
| `--ink-2` | `rgb(207 211 214)` | 8.9:1 |
| `--ink-3` | `rgb(173 178 184)` | 5.7:1（对 ground） |
| `--accent` | `rgb(122 170 255)` | deepseek-400 |
| `--accent-wash` | `rgb(68 68 70)` | 老大气泡 |
| `--danger` | `rgb(242 90 90)` | — |

**层次不能倒过来**：深色下侧栏必须比主区**亮**（27 比 21），否则侧栏像一个洞。
这一条写错，整个界面立刻失去层次 —— DSH 也是这么分的。

## 3. 人：画出来的头像

不用图片、不用 emoji、不用字母色块。`js/avatar.js` 生成 SVG：

- 三个外形，按 `hash(slug) % 3` 选：**圆胖 / 带角 / 方肩**。100×100 viewBox，`--ink` 描边 0 填充 + 一个浅色底。
- **眼睛用 `<mask>` 挖洞**（透出底色）。这一条是「高级」和「廉价」的分水岭，必须做。
- 底色：每人一个**淡**色（明度 > 92%），按固定顺序取，相邻的人色相至少差 60°。
  **这是身份，不是数据**——不进图表、不做图例。
- 尺寸：`--av-sm: 20px`、`--av-md: 24px`、`--av-lg: 40px`。
- `transform-origin: 50% 100%`（从脚底变形）。

### 3.1 四个状态（只有四个）

| 状态 | 什么时候 | 动什么 | 时间 |
|---|---|---|---|
| `idle` | 默认 | 不动 | — |
| `thinking` | 有 `think` 投影在跑 | 歪头 `rotate(±4deg)` | 2.2s 往复 |
| `working` | 有 `tool` 投影在跑 | 上下 `translateY(-2px)` + 每 2.4s 眨一次眼（`scaleY(.1)` 的 `<g>`） | 1.6s / 2.4s |
| `done` | 刚交付，播一次 | 压扁 `scaleY(.9)` 再弹回 | 1.8s，`forwards` |

`@media (prefers-reduced-motion: reduce)` 时全部 `animation: none`。

### 3.2 群组头像（公司层频道用）

2×2 排四个，每个缩到 55%，间距 4%，用 `mask` 的 `radial-gradient` + `mask-composite: intersect`
让交界处互不糊。不足四个就少画。

## 4. 字

**字体栈照抄 DSH，因为这就是「像原生应用」的原因**：

```css
--sans: -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB",
        "Microsoft YaHei", "Helvetica Neue", Helvetica, Arial, sans-serif;
--mono: "SF Mono", "JetBrains Mono", "Fira Code", Consolas, "Liberation Mono", Menlo, Courier,
        "PingFang SC", "Microsoft YaHei";   /* 故意不加裸 monospace：Windows 中文会落到宋体 */
--brand: "Montserrat", var(--sans);          /* 只给侧栏那个 logo 用，本地 woff2 */
```

- **正文不用 webfont。** v2 用 IBM Plex 给一个中文界面定型，反而把它做成了「一个网页」。
  `plex-*.woff2` 已不再被引用（文件留在 `ui/web/fonts/` 里，随时可删）。
- `Montserrat` 只用在 `Solo` 那个 wordmark 上（正好是拉丁字母，Montserrat 有字形）（300/400/500 三个 woff2，OFL 许可见同目录
  `Montserrat-OFL.txt`）。中文没有字形，回落到系统栈。
- **数字** 一律 `font-variant-numeric: tabular-nums` + `--mono`（时间、耗时、条数、序号）。

**字号只有这么几档：**

| 用途 | 字号/行高 | 字重 |
|---|---|---|
| 正文（消息、输入框） | 14 / 24 | 400 |
| 次级（过程行、副标题、按钮） | 13 / 20 · 13 / 24 | 400 / 500 |
| 行名、侧栏标题 | 14 / 20 | 500 |
| 频道标题（标题行） | 15 / 20 | 500 |
| 品牌 wordmark | 18 / 24，letter-spacing .04em | 600 |
| meta、时间、标签 | 12 / 18 · 11 / 14 | 400 |
| 微字（相对时间） | 10 / 14 | 400 |

字重只有 400 / 500 / 600。**不许 700**（markdown 的 h1–h3 除外）。正文 `text-wrap: pretty` +
`overflow-wrap: anywhere`。

## 5. 消息：四种行，别的都不是行

`js/rows.js` 里一张表定死：`ROWS = { say, event, note }`。**未命中的 kind 一律不画**。

（旧稿里的 `pending` 行已废弃：V2 没有待办卡这个对象，拍板就是一条带 `needsYou` 的发言，见 §5.4。）

### 5.1 `say` —— 有人说话（`kind: decision | report | question | undefined`）

```
[40px 槽] 名字 13/500 角色 11/400 时间 10 mono
          正文 14/24，最多 calc(100% - 76px)（右边 76px 是动作条的走廊）
```

- **默认是平铺**，不是气泡。名字行在上，正文在下。
- 连续同一个人发言（同一人、间隔 < 2 分钟）：只有第一条画名字和头像，后续行缩进对齐、`margin-top: 2px`。
- **气泡开关**：顶栏菜单里「气泡 / 平铺」，存 `localStorage["ai-company.layout"]`，
  挂在 `body[data-layout]`。
  气泡模式下：
  - 正文包一层带 `--accent-wash` 底的圆角块（`--r-xl` = 20、22/24、padding 10/16），并且
    **`width: fit-content`** —— 短句就是一小块，长段落最多 68ch。「贴内容长」是气泡与
    平铺真正的区别；只加底色不加这条，两种模式看起来一模一样（第一版就是这样）。
  - **老大的话靠右**：行是 grid（头像列 + 正文列），所以靠右要用
    `grid-template-columns: minmax(0,1fr) var(--av-lg)` 把两列互换、头像落到第 2 列、
    正文 `justify-self: end`，而不是 `justify-content`。底色换 `--accent-wash`，
    整宽出血色带只存在于平铺模式。
  - 动作条 `left: auto; right: 100%` —— 气泡靠右时，那 82px 留白在左边。
  - **连续发言的圆角收口**用逻辑属性：
    ```css
    .row-say[data-grouped="true"] .md { border-start-start-radius: var(--r-control); }
    ```
  - 纯附件消息的占位正文（`[图片] 宽图.png`）**不排**：图片已经画在图里、文件名已经在
    文件卡里，再排一遍是同一件事说两次。`rows.js` 用 `/^\[(图片|文件)\]\s/` 判。
- 一行的读法是「**谁 · 什么角色 · 要我做什么 · 什么时候**」，所以头部的顺序固定：
  名字 → 角色 → 「需要你」（`--accent`，前面一条 1px 竖线分隔）→ 时间。
  「需要你」不做成药丸 —— 药丸会被读成按钮。
  **时间紧跟在角色后面，不要 `margin-left: auto` 靠右**：正文卡在 68ch，时间靠右会落在
  那条边线上 —— 短消息时它浮在半空、离名字半个屏幕，看着像另一个人说的话。
- 正文里 `@名字` 加 `--accent` 文字（无底色）。
- 老大自己说的话：**靠右**（两列互换，头像换到右侧列），底色是贴着正文的 `--accent-wash`
  圆角块，宽度跟随内容。**不用整宽出血色带**——靠右之后那条色带会横贯 1142px 只为了包住
  右边一小块字，读起来像分隔条。**平铺布局也靠右**：靠左对齐时老大和别人的话长得一模一样。

### 5.2 `event` —— 过程，一句话，**可展开**

`think` / `tool` / `work` 投影画成一行 12px `--ink-3`，例如
`周砚 读了 channel/state.ts`、`周砚 跑了一条命令`、`周砚 想了一会儿`。

**居左**，左缘和 `say` 的正文对齐（`margin-left: 48px` = 40 头像 + 8 间距）。居中会让
一屋子过程行变成一条虚线的中轴，读起来像系统日志而不是「谁在干什么」。

**可展开**：这一行是个 `<button data-act="expand">`，点了在下面展开 `.ev-body pre`
（等宽 12/18、`max-height: 320px`、可滚）。正文用 `textContent` 灌原始文本，
**不过 Markdown**——工具返回体里有 HTML 和尖括号，过渲染器等于开一个注入面。

工具名 → 人话的映射表写死在 `rows.js`（`TOOL_PHRASES`），**只翻 17 个**，未命中就画
`在做一件事`。摘要那一行**绝不画工具卡、不画参数**；要看参数是展开之后的事。

`think` 不逐条画：把连续 think 合成一行，末尾带秒数（`想了 12s`）。

### 5.3 `note` —— 系统说的话

12px、`--ink-3`、左边 1px `--rule` 竖线、内缩 12px。**不居中、不加底色。**

### 5.4 `decision` —— 拍板（正文行，不是卡片）

**V2 没有「待办卡」这个 UI 对象**，也没有投票按钮或 `/api/answer`。拍板就是一条普通发言，
只是 `kind: "decision"`，外加 `needsYou` 标记。所以它走 `say` 的排版，只多三件事：

- 名字后面跟一个 12px `--ink-3` 的 `拍板` 字样（不是彩色徽章），让老大一眼认出这是他该定的。
- 左侧 2px `--accent` 竖线（`needsYou` 自带）。
- 字号不提、底色不加。**它是消息，不是表单。**

老大直接在输入框回答即可——这就是 V2 的设计：**没有另一条交互通道，回答就是发言**。

### 5.5 时间

同一天内间隔 > 30 分钟插一条 12px 居中 `--ink-3` 时间（`14:32`）。
跨天插 `昨天` / `10 月 27 日`。**不在每条消息上重复时间**——只有连续发言的第一条显示。

## 6. 消息的动作

- 动作条挂在**正文右侧外面**，永不遮正文：
  ```css
  .row { position: relative; }
  .row-tools { position: absolute; left: 100%; top: 2px; margin-left: 6px;
               opacity: 0; visibility: hidden; transition: opacity .12s ease, visibility .12s; }
  .row-tools::after { content: ""; position: absolute; inset: -8px -8px -8px 0; z-index: -1; } /* 悬停桥 */
  .row:hover > .row-tools, .row:focus-within > .row-tools { opacity: 1; visibility: visible; }
  ```
  正文 `max-width: calc(100% - 76px)` —— 那 76px 就是给动作条的（6 间距 + 28 + 8 + 28）。
- 按钮 28×28、图标 15px、圆角 8、间距 8；显隐只动 `opacity`（80ms），**不许 `display:none`**
  —— 鼠标划过一条消息时不能引起任何位移。
- 两个动作，固定顺序：**复制** / **引用回复**。
  曾经还有第三个「定位」（滚到这条并高亮 1.2s），但它和「点行本身就滚到这条」重复，老大问
  「那个定位是干嘛的？没用就删掉」—— 删了。同一个动作不留第二个入口。
- 复制成功：图标变对勾 1.2s，不弹 toast。
- 触屏（`@media (hover: none)`）：动作条常驻、缩小到 20px、`--ink-3`。

## 7. 输入

```
┌─────────────────────────────────────────────┐
│ 回复 周砚：坦克大战要不要…            ✕      │  ← 1px 下边线的条，12px
├─────────────────────────────────────────────┤
│ ＋  发消息…（@ 提人）                    ↑   │  ← --field 底 / 半径 28 / 0.5px 描边画在阴影里
└─────────────────────────────────────────────┘
```

- 卡片：`--field` 底、圆角 28、`box-shadow: 0 0 0 0.5px var(--line), 0 4px 16px 3%, 0 0 24px 3%`。
  描边画在阴影里，所以第 52px 高度不被边框吃掉；宽度卡在「消息列宽 + 32」。
- `textarea` 自增高 28 → 336px（14 行 × 24），超出滚动。焦点**不加阴影、不加光晕**，
  只把描边加深到 `--control`，光标 `caret-color: var(--accent)`。
- `＋`：28px 满圆、`--raised` 底、图标 14。
- 发送键：**34px 满圆**（比 ＋ 大一圈，视觉重心在这里）、`--accent` 底、白色 16px 上箭头；
  禁用时同色 `opacity: .4`。空输入 + 无附件 = disabled。
- Enter 发送 / Shift+Enter 换行；**`isComposing || keyCode === 229` 时不发送**（中文输入法）。
- `@` 弹窗：白底、1px `--line`、`--r-row`、无阴影外还加一层 `0 1px 2px rgba(0,0,0,.06)`；
  每行 24px 头像 + 名字 13/500 + 职位 11px `--ink-3`；上下键选中行 `--hover`。

## 8. 动效（手感来自这一节）

`js/motion.js` 生成弹簧曲线（阻尼谐振采样 25 点 → `linear(...)`），启动写进 CSS 变量：

| 名字 | 用途 | 时长 |
|---|---|---|
| `--ease-tap` / `--dur-tap` | 按下、切换、滑块 | 180ms |
| `--ease-pop` / `--dur-pop` | 浮层出现 | 240ms |
| `--ease-sheet` / `--dur-sheet` | 面板开合 | 320ms |

- **入场**：`@keyframes veil-in { from { opacity:0; filter: blur(6px) } }`，240ms。
- **退场**：`pop-out { to { opacity:0; transform: scale(.97); filter: blur(2px) } }`。
  关闭浮层不立刻 `remove()`：加 `data-leaving`，180ms 后（reduced-motion 时 0ms）再摘。
- **活动行**：一行，永远只有一行。文字流光 `background-clip: text` + `steps(60)` 2.2s，
  但**每句至少停 800ms**。消失时如果页面钉在底部，用 WAAPI 补 `translateY(-delta)` 140ms 补偿高度差。
- 不许对 `height` 做 transition（会抖）；用 `max-height` 或 FLIP。

## 9. 空、加载、错误

- **加载**：最终布局 + 每个值换成同尺寸的灰色实心条（24px 的值就是 24px 高的条），**不做 shimmer 渐变**，
  数据到达后不跳位置。
- **空**（没有消息）：保留纸的框和标题，在消息区放一句话 + 一个动作。
- **错误**：在出错的那一块里面一句话 + 「重试」文字按钮，**不用全屏横幅**，不用红色底色。
- **断线**：顶栏右侧一个 12px `--warn` 文字「连不上，10:42 最后一次成功」，恢复后自己消失。

## 11. 移动端

- 一次只显示一个区域：`.sidebar` 与 `.sheet` 同一格（`grid-area: main`），靠
  `body[data-pane]` 切。`#back` 是第一屏唯一的回退入口。
- **`viewport-fit=cover` 声明了就必须让安全区**：`<meta name="viewport">` 里写了
  `viewport-fit=cover`，所以
  - `.topbar` 加 `padding-top: env(safe-area-inset-top)`，**同时**把 frame 的那一行改成
    `calc(var(--topbar) + env(safe-area-inset-top))` —— 否则 `border-box` 下 padding 会把
    48px 顶栏的内容挤成 0；
  - `.composer` 的底部 padding 加 `env(safe-area-inset-bottom)`，不然「发送」压在手势条上；
  - 侧栏左右也加 `env(safe-area-inset-left/right)`。
  `env()` 在无刘海设备上是 0，等价于原值。高度用 `100dvh`（不是 `100vh`），地址栏伸缩时不跳。
- 动作条不绝对定位（桌面那套 `left: 100%` 在手机上会跑到屏幕外）：改成 `static`，
  点一下那一行才显示（`data-tools="true"`），点空白或 Esc 收起。

## 详情面板：从右边展开

`#detail` 是透明层 + `pointer-events: none`，`.detail-panel` 贴右、宽 `min(420px, 100%)`、
从顶栏下沿开始（`padding-top: calc(var(--topbar) + env(safe-area-inset-top))`）、只有
`border-left` 和一道 16px 的 `translateX` 入场。**不压暗、不居中、不 inert** —— 这不是弹窗，
是一条可以一边看一边继续说话的竖栏。手机 ≤640px 铺满整屏。
