# 界面设计（锁定稿）

> 这份文件是**决策**，不是建议。改它要先说明为什么原决策错了。
> 依据：`design-taste-frontend` skill 的 app-screens 章节 + 摇出的 `Framed sheet` 方向（seed 3117）。
> 检验方式：`node ~/.pi/agent/skills/design-taste-frontend/scripts/inspect.mjs <url> --app`，**必须 0 FAIL**。

## 0. 为什么是这个方向

改造前的实测（`.taste-skill/before/report.json`）：2 FAIL 1 WARN，字号全部挤在 10–16px，
typefaces 只有 `-apple-system` + `ui-monospace`，0 张图，没有 h1，正文对比度 4.4:1。

更要紧的是它长得像**所有生成式仪表盘的平均值**：暗底 + 深色侧栏 + 彩块字母头像 + 紫色胶囊按钮。
skill 把这一条列成「生成式仪表盘第一号特征」。

所以换的不只是颜色，是**渲染模型**：

- 没有「消息列表」，只有**四种行**（§5）。加一种消息不用改四处。
- 没有「头像色块」，只有**画出来的人**（§3）。
- 没有「用颜色分层级」，只有**一条字号阶梯 + 一个强调色**（§2）。
- 颜色只上数据，不上 chrome（§2.4）。

## 1. 外壳：取景框 + 白纸

```
┌───────────────────────────────────────────────┐  ← 框（暖石色 #f7f6f2）
│ mark 一人公司 · 4 个项目 · 8 个人   N 件找你 ⟳ │  48px，与侧栏之间**没有分隔线**
├──────────────┬────────────────────────────────┤
│ 人            │ ┌────────────────────────────┐ │  ← 白纸（inset 8 / 半径 16 / 1px 边 / 无阴影）
│  ○ 林越       │ │ 公司大群          22/600    │ │
│  ○ 周砚       │ │ 8 人 · 今天 12 条            │ │
│  频道         │ ├────────────────────────────┤ │
│  公司大群  2  │ │  消息流（§5）               │ │
│  领导层       │ │                            │ │
│               │ ├────────────────────────────┤ │
│               │ │ 输入（§7）                  │ │
└──────────────┴────────────────────────────────┘
```

- **框**：侧栏（240px）+ 顶栏（48px）共用同一个 `--frame`，两者之间**不画线**。这是这一版的「手法」。
- **纸**：右、下各内缩 8px，圆角 16，1px `--line`，**没有阴影**。层次靠一个色阶。
- **选中项**：中性 `--active` 填充，**不是**彩色胶囊；当前频道在顶栏标题里，不需要彩色按钮再说一遍。
- **产品标记**：一个 18×18 的 SVG（1.5px 描边圆 + 一个竖直小刻度，`--ink`），旁边 `一人公司` 15/600。
  **不要**黑方块加字母。
- 顶栏右侧：`N 件找你`（`--mono`，是按钮，点了跳到下一条需要老板的消息）+ 刷新图标。
  未读为 0 时显示灰色 `0`，不隐藏（诚实的零）。

### 1.1 产品独有的一个元素：**人栏**

侧栏顶部不是频道，是**这家公司的人**：8 个人，每人一行 40px，24px 头像 + 名字 13/500 + 状态 11px。
状态只有四种，用词不用图标：`在想` / `在做` / `待命` / `睡了`，颜色只在「在做」时是 `--live` 小点。

这是这个产品唯一有的东西——**你能看见你的公司在干活**。任何改动都不许把它砍掉。

### 1.2 需要老板的消息 = 「找你」

后端已经把「这条要不要老板看一眼」判好了（`needsYou` 字段，判据在核心：`needsOwner()` 的 7 个信号
或显式 `@owner`，老板自己说的永不算）。界面只做三件事：

1. **就地标记**：这类消息左侧 2px `--accent` 竖线 + 12px `需要你` 文字（`--accent`，**无底色**）。
2. **顶栏计数**：`GET /api/attention` 返回 `{ items, unread }`。顶栏显示 `N 件找你`（N = `unread`，
   `--mono`）。0 件时显示灰色 `0`，不隐藏。
3. **跨频道定位**：点 `N 件找你` 打开一个浮层，按时间倒序列出**所有频道**里等老板开口的消息：
   每行 = 频道名 · 谁 · 一句话摘要（80 字）· 相对时间。点一行 = 切到那个频道并滚到该 `seq`、高亮 1.2s。
   已读的照列（`read: true` 淡化到 `--ink-3`）——读过了和没看见是两件事。

**这是本项目回答「消息太多、我找不到该看哪条」的唯一机制，不许省。**
不要做一列固定侧栏，它吃掉会话宽度；浮层就够。

### 1.3 手机（≤640px）

框消失：纸铺满屏幕，顶栏压到 48px（菜单按钮 + 标题 + 一个动作）。**一次只显示一个区域**：
列表铺满 → 点一个频道推进会话 → 返回回到列表原位置。侧栏不许超过屏宽 30%。

## 2. Token（全部锁定，不许新增颜色）

```css
:root {
  /* 面 */
  --frame: #f7f6f2;      /* 框：暖石。这是本产品的「脸」，来自「一张桌子 / 抬头纸」 */
  --ground: #ffffff;     /* 纸 */
  --raised: #faf9f6;
  --hover: rgba(28, 26, 22, 0.045);
  --active: rgba(28, 26, 22, 0.075);
  /* 线 */
  --line: #e8e5de;
  --rule: #f0eee9;
  --control: #d8d4cb;
  /* 墨 */
  --ink: #1c1a16;
  --ink-2: #55524b;      /* 6.9:1 —— 正文与副标题 */
  --ink-3: #6b665c;      /* 5.0:1 —— meta、时间、标签。不许再浅 */
  /* 强调（只上数据与一处控件） */
  --accent: #2b5f4f;     /* 深松绿。不是紫/靛，不是奶白配赤陶 */
  --accent-wash: #edf3f0;
  --live: #2b5f4f;
  --warn: #92400e;
  --danger: #b3261e;
  /* 形状 */
  --r-sheet: 16px;
  --r-row: 8px;
  --r-control: 6px;
  --inset: 8px;
  --sidebar: 240px;
  --topbar: 48px;
  --pad: 24px;
  --gap: 12px;
}
```

**规则：**

1. **颜色只上数据，不上 chrome。** 整个屏幕彩色像素 < 3%。强调色只出现在：2px「需要你」竖线、
   `--live` 小点、滑块/焦点环。没有彩色按钮、没有彩色胶囊、没有彩色图标底。
2. **主按钮是近黑 `--ink`**，不是强调色。
3. `--accent-wash` 只给「老板自己说的话」的整宽色带用（让人一眼找到自己的话）。
4. 状态色只用于**真出问题**的时候（失败、超时）。零和正常一律 `--ink-3`。
5. 不许渐变、不许发光、不许玻璃/backdrop-blur、不许阴影（浮层例外：菜单、popover、输入卡、dialog）。

## 3. 人：画出来的头像

不用图片、不用 emoji、不用字母色块。`js/avatar.js` 生成 SVG：

- 三个外形，按 `hash(slug) % 3` 选：**圆胖 / 带角 / 方肩**。100×100 viewBox，`--ink` 描边 0 填充 + 一个浅色底。
- **眼睛用 `<mask>` 挖洞**（透出底色）。这一条是「高级」和「廉价」的分水岭，必须做。
- 底色：每人一个**淡**色（明度 > 92%），按固定顺序取，相邻的人色相至少差 60°。
  **这是身份，不是数据**——不进图表、不做图例。
- 尺寸：`--av-sm: 20px`、`--av-md: 24px`、`--av-lg: 40px`。
- `transform-origin: 50% 100%`（从脚底变形）。

### 3.1 四个状态（只有四个）

| 状态 | 什么时候 | 动什么 | 时间 |
|---|---|---|---|
| `idle` | 默认 | 不动 | — |
| `thinking` | 有 `think` 投影在跑 | 歪头 `rotate(±4deg)` | 2.2s 往复 |
| `working` | 有 `tool` 投影在跑 | 上下 `translateY(-2px)` + 每 2.4s 眨一次眼（`scaleY(.1)` 的 `<g>`） | 1.6s / 2.4s |
| `done` | 刚交付，播一次 | 压扁 `scaleY(.9)` 再弹回 | 1.8s，`forwards` |

`@media (prefers-reduced-motion: reduce)` 时全部 `animation: none`。

### 3.2 群组头像（公司层频道用）

2×2 排四个，每个缩到 55%，间距 4%，用 `mask` 的 `radial-gradient` + `mask-composite: intersect`
让交界处互不糊。不足四个就少画。

## 4. 字

**两个字体，各一个职责**：

- `IBM Plex Sans` 400/500/600 —— 所有文字。本地文件在 `ui/web/fonts/plex-sans-*.woff2`，`@font-face` 加载，
  **不许只写 font-family 而不加载文件**。中文回落 `"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei"`。
- `IBM Plex Mono` 400/500 —— **所有数字**：时间、序号、耗时、条数、花费、频道 id。本地文件 `plex-mono-*.woff2`。

**字号阶梯只有 6 档，别的不许出现：**

| 用途 | 字号/行高 | 字重 |
|---|---|---|
| 页面标题（频道名） | 22 / 28 | 600 |
| 小节标签、对话框标题 | 16 / 24 | 500 |
| 正文（消息内容） | 14 / 24 | 400 |
| 行名、小按钮 | 13 / 20 | 500 |
| meta、时间、标签、副标题 | 12 / 16 | 400 |
| 徽标、micro | 11 / 14 | 400 |

字重只有 400 / 500 / 600。**不许 `font-weight: 700`。** 数字一律 `font-variant-numeric: tabular-nums`。
纯英文标签不用 `text-transform: uppercase` + 字距。正文 `text-wrap: pretty` + `overflow-wrap: anywhere`。

## 5. 消息：四种行，别的都不是行

`js/rows.js` 里一张表定死：`ROWS = { say, event, note }`。**未命中的 kind 一律不画**。

（旧稿里的 `pending` 行已废弃：V2 没有待办卡这个对象，拍板就是一条带 `needsYou` 的发言，见 §5.4。）

### 5.1 `say` —— 有人说话（`kind: decision | report | question | undefined`）

```
[40px 槽] 名字 13/500 ······· 时间 11 mono
          正文 14/24，最多 max-width 68ch
```

- **默认是平铺**，不是气泡。名字行在上，正文在下。
- 连续同一个人发言（同一人、间隔 < 2 分钟）：只有第一条画名字和头像，后续行缩进对齐、`margin-top: 2px`。
- **气泡开关**：顶栏菜单里「气泡 / 平铺」，存 `localStorage["ai-company.layout"]`。
  气泡模式下：正文包一层 `.bubble`（`--raised` 底、`--r-row` 圆角、14/24、padding 10/14），
  **连续发言的圆角收口**用逻辑属性：
  ```css
  .row-say:not(:first-child) .bubble { border-start-start-radius: 6px; }
  .row-say:not(:last-child)  .bubble { border-end-start-radius: 6px; }
  ```
- 正文里 `@名字` 加 `--accent` 文字（无底色）。
- 老板自己说的话：整宽 `--accent-wash` 色带（左右各 -8px 出血），让人觉得是自己的回合。

### 5.2 `event` —— 过程，一句话

`think` / `tool` / `work` 投影**全部画成一行居中、12px、`--ink-3`**，例如
`周砚 读了 channel/state.ts`、`周砚 跑了一条命令`、`周砚 想了一会儿`。

工具名 → 人话的映射表写死在 `rows.js`（`TOOL_PHRASES`），**只翻 17 个**，未命中就画
`在做一件事`。**绝不画工具卡、不画参数、不画返回体。**

`think` 不逐条画：把连续 think 合成一行，末尾带秒数（`想了 12s`）。

### 5.3 `note` —— 系统说的话

12px、`--ink-3`、左边 1px `--rule` 竖线、内缩 12px。**不居中、不加底色。**

### 5.4 `decision` —— 拍板（正文行，不是卡片）

**V2 没有「待办卡」这个 UI 对象**，也没有投票按钮或 `/api/answer`。拍板就是一条普通发言，
只是 `kind: "decision"`，外加 `needsYou` 标记。所以它走 `say` 的排版，只多三件事：

- 名字后面跟一个 12px `--ink-3` 的 `拍板` 字样（不是彩色徽章），让老板一眼认出这是他该定的。
- 左侧 2px `--accent` 竖线（`needsYou` 自带）。
- 字号不提、底色不加。**它是消息，不是表单。**

老板直接在输入框回答即可——这就是 V2 的设计：**没有另一条交互通道，回答就是发言**。

### 5.5 时间

同一天内间隔 > 30 分钟插一条 12px 居中 `--ink-3` 时间（`14:32`）。
跨天插 `昨天` / `10 月 27 日`。**不在每条消息上重复时间**——只有连续发言的第一条显示。

## 6. 消息的动作

- 动作条挂在**正文右侧外面**，永不遮正文：
  ```css
  .row { position: relative; }
  .row-tools { position: absolute; left: 100%; top: 2px; margin-left: 6px;
               opacity: 0; visibility: hidden; transition: opacity .12s ease, visibility .12s; }
  .row-tools::after { content: ""; position: absolute; inset: -8px -8px -8px 0; z-index: -1; } /* 悬停桥 */
  .row:hover > .row-tools, .row:focus-within > .row-tools { opacity: 1; visibility: visible; }
  ```
  正文 `max-width: min(68ch, calc(100% - 82px))` —— 那 82px 就是给动作条的。
- 三个动作，固定顺序：**复制** / **引用回复** / **定位**（滚动到这条并高亮 1.2s）。
- 复制成功：图标变对勾 1.2s，不弹 toast。
- 触屏（`@media (hover: none)`）：动作条常驻、缩小到 20px、`--ink-3`。

## 7. 输入

```
┌─────────────────────────────────────────────┐
│ 回复 周砚：坦克大战要不要…            ✕      │  ← 1px 下边线的条，12px
├─────────────────────────────────────────────┤
│ 发消息…（@ 提人）                     [发送] │  ← 白底 / 1px --line / 半径 22 / 无阴影
└─────────────────────────────────────────────┘
```

- `textarea` 自增高 44 → 160px，超出滚动。焦点时边线变 `--control`，**不加阴影、不加光晕**。
- 发送按钮：`--ink` 底、`#fff` 字、13/500、`--r-control`、32px 高。空输入时 `--control` 底 + `--ink-3` 字，`disabled`。
- Enter 发送 / Shift+Enter 换行；**`isComposing || keyCode === 229` 时不发送**（中文输入法）。
- `@` 弹窗：白底、1px `--line`、`--r-row`、无阴影外还加一层 `0 1px 2px rgba(0,0,0,.06)`；
  每行 24px 头像 + 名字 13/500 + 职位 11px `--ink-3`；上下键选中行 `--hover`。

## 8. 动效（手感来自这一节）

`js/motion.js` 生成弹簧曲线（阻尼谐振采样 25 点 → `linear(...)`），启动写进 CSS 变量：

| 名字 | 用途 | 时长 |
|---|---|---|
| `--ease-tap` / `--dur-tap` | 按下、切换、滑块 | 180ms |
| `--ease-pop` / `--dur-pop` | 浮层出现 | 240ms |
| `--ease-sheet` / `--dur-sheet` | 面板开合 | 320ms |

- **入场**：`@keyframes veil-in { from { opacity:0; filter: blur(6px) } }`，240ms。
- **退场**：`pop-out { to { opacity:0; transform: scale(.97); filter: blur(2px) } }`。
  关闭浮层不立刻 `remove()`：加 `data-leaving`，180ms 后（reduced-motion 时 0ms）再摘。
- **活动行**：一行，永远只有一行。文字流光 `background-clip: text` + `steps(60)` 2.2s，
  但**每句至少停 800ms**。消失时如果页面钉在底部，用 WAAPI 补 `translateY(-delta)` 140ms 补偿高度差。
- 不许对 `height` 做 transition（会抖）；用 `max-height` 或 FLIP。

## 9. 空、加载、错误

- **加载**：最终布局 + 每个值换成同尺寸的灰色实心条（24px 的值就是 24px 高的条），**不做 shimmer 渐变**，
  数据到达后不跳位置。
- **空**（没有消息）：保留纸的框和标题，在消息区放一句话 + 一个动作。
- **错误**：在出错的那一块里面一句话 + 「重试」文字按钮，**不用全屏横幅**，不用红色底色。
- **断线**：顶栏右侧一个 12px `--warn` 文字「连不上，10:42 最后一次成功」，恢复后自己消失。
