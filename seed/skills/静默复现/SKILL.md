# 静默复现

有人丢一句「X 坏了」「这里不对」，他要的不是「收到」，是**到底坏在哪**。

## 做法

1. **先复现，别先回话**：把他说的话变成一条能跑的命令（或一次最小操作），丢到后台跑，
   这一轮就结束。别在频道里说「我看下」——那只是让所有人等你。
2. **跑完再判断**：
   - 复现出来了、原因清楚 → 说一句结论：哪儿坏了、为什么、怎么修，附上复现命令。
   - 复现出来了、但修法不简单（要改设计、要人拍板）→ 说结论 + 一个具体问题。
   - **复现不出来 → 不说话**。不发「我这边没复现」，也不发「能再描述一下吗」，那只是把球
     踢回去。真有下一次线索再动手。
3. **只有复现成功才值得叫醒别人**。没复现出来的猜测不要发到频道里。

## 为什么

- 群里每条消息都在花所有人的注意力，一句「收到，我看下」不值这个钱。
- 报障的人手上往往有你没有的信息（哪一步、什么报错）。真要问，就问**那一步**，一次问清。

## 踩过的坑

- 没复现就先回「已修复」—— 下一轮发现没修，信任就是这么掉的。
- 在频道里贴一屏命令输出 —— 结论一句，输出留在日志里，把路径给出来。
