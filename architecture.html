边界是机械检查的

npm run check 跑 tsc 与 check-boundaries； 违反任何一条即失败。不是靠自觉。

  • 只有 core/runtime 能 import 底层库（pi-durable / pi-ai / chord）
  • 内核不反向 import 上层：agent / team / channel / runtime 不碰 app / view / interface / shell
  • 每条路由必须有前端消费者（白名单只有 /api/org）
  • view 是契约层：只有 dto.ts，零 import
  • app 不 import node:http：用例要能脱离网络直接测
  • interface 只经 app 与 view 说话，不 import 领域内部实现
  • md 只能往下看：可 import runtime 与 fsx，不许够上层
  • 根原语不向上：fsx / naming 不 import app / view / interface / shell
  • plugin 只加东西：工具 / 提示词 / 路由 / 听消息，由 shell 并进注册表
